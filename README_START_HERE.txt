STOICHIOMETRY — INTERACTIVE HTML LECTURE (NO SCORM)

HOW TO USE
1. Extract this ZIP completely, preserving its folders.
2. Open index.html in a modern browser (Chrome, Edge, Firefox).
3. Press F11 for browser fullscreen.
4. Switch Hebrew/Arabic via the top button.
5. S1, S2, S3, S4, S6 and S7 launch as separate HTML pages.
6. This HTML website has no SCORM manifest or SCORM player.

MOODLE DEPLOYMENT
For the full browser viewport, host the entire extracted folder on a web server
and link to index.html using a Moodle URL resource set to open in a new window.
Do NOT upload only index.html: mathjax and linked activity files are needed.
You can also run the site locally by opening extracted index.html.
Moodle completion/grades are not tracked by this HTML-only site.
